# ماذا تفعل في Supabase الآن

## خطوة واحدة فقط

**SQL Editor ← New query ← الصق كل `supabase/INSTALL_ALL.sql` ← Run**

هذا يكفي. الملف آمن لإعادة التشغيل ولا يفقد أي بيانات، ويشمل كل شيء:
الجداول، سياسات الحماية، الدوال، طبقة المزامنة، والصيانة.

بعده تحقق أن النتيجة تُظهر: `التثبيت اكتمل ✔`

## ثم مرة واحدة: تأكد أن كل عميل له رمز مزامنة

```sql
select business_name as المصنع,
       id as tenant_id,
       (sync_token is not null) as له_رمز,
       sync_enabled as المزامنة_مفعّلة
  from public.tenants
 order by business_name;
```

كل الصفوف يجب أن تكون `له_رمز = true`. لو ظهر `false` لأحدهم، أعد تشغيل
`INSTALL_ALL.sql` — القسم الخاص بذلك ينشئ الرموز تلقائياً.

# جعل الـ ١ جيجا تكفي أطول فترة ممكنة

## أولاً: اعرف رقمك الحقيقي

```sql
select * from public.storage_summary();
```

يعطيك: المساحة المستهلكة، عدد الحركات، ونسبة الامتلاء.

> تنبيه: الـ ١ جيجا في حسابك هي مساحة **Storage** (الملفات) — ونحن لا نخزّن
> ملفات إطلاقاً. الحد المهم هو **٥٠٠ ميجا لقاعدة البيانات**.
> راجعه في: Settings ← Usage ← Database size.

## ثانياً: صيانة كل ٣ شهور (دقيقة واحدة)

```sql
select * from public.run_maintenance();
```

تحذف سجلات المراقبة القديمة فقط. **الحركات المحاسبية لا تُمس إطلاقاً.**

## ثالثاً: أرشفة سنوية (توفّر أكثر من النصف)

في بداية كل سنة، احذف من السحابة حركات ما قبل سنتين — تبقى محفوظة كاملة
على أجهزة العملاء وفي نسخهم الاحتياطية.

```sql
-- ١) اطّلع أولاً على ما سيُحذف (لا يحذف شيئاً)
select period, count(*) as الحركات
  from public.transactions
 where txn_date < now() - interval '2 years'
 group by period order by period;

-- ٢) نفّذ الحذف بعد التأكد
delete from public.transactions
 where txn_date < now() - interval '2 years';

select * from public.run_maintenance();
```

## كم تكفي فعلياً؟

| عدد المصانع | حتى ٥٠٠ ميجا | مع الأرشفة السنوية |
|---|---|---|
| مصنع واحد | ٧ سنوات | أكثر من ١٥ سنة |
| ٣ مصانع | سنتان ونصف | ٦ سنوات |
| ٥ مصانع | سنة ونصف | ٤ سنوات |
| ١٠ مصانع | ٨ شهور | سنتان |

## متى ترقّي؟

راقب `storage_summary()`. عندما تصل **٧٠٪** ابدأ التفكير:

- **أقل من ٥ مصانع:** المجاني يكفيك سنوات مع الصيانة والأرشفة.
- **٥ إلى ١٠:** رقِّ خلال سنة.
- **أكثر من ١٠:** رقِّ مباشرة — خطة Pro بـ ٢٥ دولار شهرياً تعطيك ٨ جيجا
  (١٦ ضعفاً) وتكفي ٢٠ مصنعاً لأكثر من ٥ سنوات.
