# برنامج سطح المكتب — نسخة العميل ونسخة المدير

## الملفات

| الملف | الوظيفة |
|---|---|
| `rageh-1-34-14-cloud.py` | **نسخة المدير** (مصدر الكود — فيها لوحة المدير) |
| `rageh-CLIENT.py` | **نسخة العميل** — تُولَّد آلياً بـ `python make_client_build.py`، ولا تُعدَّل يدوياً |
| `make_client_build.py` | يولّد نسخة العميل: يزيل المفتاح السري ولوحة المدير |
| `gold_price.py` | سعر الذهب العالمي (شريط أسفل الشاشة) |
| `scale_reader.py` | الميزان الإلكتروني (F2) |
| `run_all_checks.py` | كل فحوص البرنامج: `python run_all_checks.py` و`python run_all_checks.py rageh-CLIENT.py` |
| `patch_client_app*.py` | سجل تاريخي لتعديلات سابقة — لا يستخدمها شيء |

## كيف تعمل البيانات (منذ الدفعة ٢١)

1. **جهاز العميل:** قاعدة SQLite هي الحقيقة، ويعمل بلا إنترنت تماماً.
2. **السحابة:** تُرفع **نسخة كاملة واحدة** من قاعدة العميل (`db_backups`) في الخلفية — بلا فهارس
   ومضغوطة بـ xz، وعند تغيّر البيانات فقط. لا تُرفع الحركات صفاً صفاً (أُزيل الويب وحركاته).
3. **برنامج المدير:** ينزّل نسخة العميل الكاملة ويعرضها كما هي حرفياً، ولا يرفع شيئاً أبداً.
4. نسخة العميل **لا تسحب من السحابة شيئاً** إطلاقاً — بياناتها لا تتغيّر إلا من شاشاتها.

## التشغيل

```bash
python rageh-1-34-14-cloud.py
```

`gold_price.py` و`scale_reader.py` يجب أن يكونا في نفس المجلد.

## البناء كملف تنفيذي

نقرة مزدوجة على **`build_client.bat`** (للعملاء) أو **`build_admin.bat`** (لك) —
التفاصيل في [`BUILD_AR.md`](BUILD_AR.md). السكربت يولّد نسخة العميل الآمنة، ويشغّل
كل الفحوص، ويبني exe ويتحقق منه.

> ⚠️ **المفتاح السري لم يعد مكتوباً داخل الكود إطلاقاً.** نسخة المدير تقرأه عند
> التشغيل من أحد مكانين:
>
> 1. متغيّر البيئة `JADEITE_SUPABASE_SECRET_KEY`، أو
> 2. ملف نصي اسمه `admin_secret.key` بجانب البرنامج (سطر واحد فيه المفتاح).
>
> الملف `admin_secret.key` مستبعد من git في `.gitignore` — **لا ترفعه ولا ترسله لأحد**.
> ونسخة العميل (`rageh-CLIENT.py`) لا تحاول قراءته أصلاً.
>
> كلمة مرور لوحة المدير المحلية تُغيَّر بمتغيّر البيئة `JADEITE_ADMIN_PASSWORD`
> (الافتراضية `admin` معروفة لكل من يقرأ الكود).
>
> **بناء نسخة العميل:** `python make_client_build.py` ثم ابنِ exe من `rageh-CLIENT.py`.
> **قبل أي تسليم:** `python run_all_checks.py rageh-CLIENT.py` — يفشل لو وُجد أي مفتاح سري في الكود.

## سلوك النظام في الحالات المختلفة

| الحالة | ماذا يحدث |
|---|---|
| انقطاع الإنترنت أثناء العمل | البرنامج يعمل طبيعياً، والنسخة الكاملة تُرفع عند عودة الاتصال |
| العميل عمل أسبوعاً بلا إنترنت | عند عودة الاتصال تُرفع نسخته الكاملة الأحدث — لا يضيع شيء |
| فشل الرفع | يُعاد تلقائياً، والبرنامج لا يتأثر |
| المدير فتح حساب العميل | يرى آخر نسخة كاملة رُفعت — كل الشاشات والأرقام والفترات كما عند العميل، وتتحدّث تلقائياً |
| نسخة عميل قديمة ما زالت ترفع الحركات | بعد تشغيل `supabase/19_remove_web.sql` يُتجاهل رفعها بهدوء بلا خطأ |
