# كيف يصل ذهب العميل إلى شاشتك — المسار كاملاً

## المسار

```
جهاز العميل                    السحابة                   جهازك أنت
─────────────                  ────────                  ──────────
١) يثبّت exe
٢) يسجّل دخوله  ──────────►  التحقق من الحساب
٣) بياناته القديمة ────────►  تُرفع كاملة
٤) تُسحب مدموجة  ◄────────  نسخة موحّدة
٥) يعمل عادي     ──────────►  كل حركة خلال ١٠ ثوانٍ
                                    │
                                    ▼
                              تدخل لوحة المدير
                              تضغط اسم العميل
                              تُسحب بياناته لجهازك
                              ترى كل شيء ◄──── ٦
```

## نعم، هذا صحيح تماماً — وهذه التفاصيل

### عند العميل (أول تشغيل بعد التحديث)

1. يفتح البرنامج ← تظهر شاشة الدخول (إجبارية في كل تشغيل، لا ملف جلسة).
2. يدخل باسمه وكلمة مروره ← يتحقق البرنامج من السحابة.
3. تظهر شاشة **«تجهيز بيانات المصنع»** بشريط تقدّم، وفيها:
   - **أولاً** تُرفع بياناته الموجودة على جهازه كاملة للسحابة
   - **ثم** تُسحب النسخة المدموجة وتُدمج محلياً (لا يُمسح شيء)
4. يفتح النظام ببياناته كما تركها بالضبط.

> الترتيب مقصود: الرفع قبل السحب. لو عكسناه لطمست نسخة السحابة الفارغة عمله.

### عندك (لرؤية حساب أي عميل)

1. افتح `rageh-1-34-14-cloud.py` (نسختك، فيها لوحة المدير).
2. سجّل الدخول بـ **admin / admin**.
3. تظهر قائمة العملاء ومعها: متصل الآن؟ آخر دخول؟ عدد حركاته؟
4. اضغط **«دخول كالعميل»** ← يسحب بياناته لجهازك مع شريط تقدّم ← يفتح نظامه كاملاً.
5. تتصفّح كل شاشاته بأرقامه هو، وأي حركة يسجّلها الآن تظهر عندك خلال ثوانٍ.
6. أي تعديل تجريه أنت يصل جهازه خلال ١٥ ثانية.

### أو من جوالك

افتح رابط لوحة الويب ← نفس القائمة ونفس زر الدخول، بلا تثبيت أي شيء.

## ضمانات مثبتة بالاختبار

| الضمان | الاختبار |
|---|---|
| بيانات العميل ترتفع كاملة | ٥٠٠ حركة صعدت ونزلت بمجموع مطابق للجرام |
| أنت ترى كل بياناته | ٥٠٠ حركة + شجرة حساباته ظهرت على جهازك |
| **كل عميل معزول** | بيانات العميل (ب) لا تظهر داخل حساب (أ) إطلاقاً |
| **رمز عميل لا يفتح حساب غيره** | العزل مفروض في الخادم لا في الواجهة |
| الحركة الجديدة تصلك | حركة سُجّلت عند العميل ظهرت عندك فوراً بقيمتها |
| لا فقد ولا تكرار | ٣٠٠٠ حركة: العدد والمجموع والتواريخ والأرقام مطابقة ١٠٠٪ |

## ثلاث نقاط عملية مهمة

**١) شغّل التحديث على جهاز العميل الأساسي أولاً.**
لو فتحه على جهاز ثانٍ فارغ قبل ذلك، سيجد النظام فارغاً لأن السحابة لم تستلم
بياناته بعد. بعد رفعها من الجهاز الأساسي يستطيع الدخول من أي جهاز.

**٢) جهاز واحد فعّال لكل مصنع.**
لو أدخل جهازان بيانات في نفس الوقت وكلاهما بلا إنترنت، سيبدآن ترقيم الفواتير
من نفس الرقم فتتصادم الحركات. الأجهزة الأخرى للاطّلاع.

**٣) أول رفع قد يستغرق دقائق.**
عميل عنده آلاف الحركات سيرى شريط التقدّم لبضع دقائق مرة واحدة فقط.
اطلب منه ألا يغلق البرنامج أثناءها (البرنامج يمنع الإغلاق تلقائياً).

## للتحقق بنفسك من السحابة

```sql
-- كم حركة وصلت من كل عميل ومتى آخر مزامنة
select t.business_name as المصنع,
       count(x.id)     as الحركات,
       max(x.synced_at) as آخر_وصول
  from public.tenants t
  left join public.transactions x on x.tenant_id = t.id
 group by t.business_name
 order by 1;

-- حالة أجهزة العملاء
select * from public.tenant_devices order by last_sync_at desc;
```
