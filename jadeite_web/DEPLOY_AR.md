# رفع لوحة الإدارة على الإنترنت — خطوات مباشرة

الهدف: رابط حقيقي تفتحه من جوالك في أي مكان.

**المنصة المختارة: Vercel** — لأن Flutter Web ينتج ملفات ثابتة (Static)، وVercel
مجاني، وسريع عالمياً، ويعطي HTTPS تلقائياً (شرط ضروري لتثبيت التطبيق كبرنامج).
`netlify.toml` مرفق أيضاً لو فضّلت Netlify — نفس النتيجة.

---

## الخطوة ١ — ارفع المشروع على GitHub

```bash
cd jadeite_web
git init
git add .
git commit -m "Jadeite ERP - admin portal"
git branch -M main
git remote add origin https://github.com/USERNAME/jadeite-web.git
git push -u origin main
```

> ملف `.gitignore` يمنع رفع أي أسرار أو ملفات بناء.

## الخطوة ٢ — اربط Vercel بالمستودع

1. ادخل [vercel.com](https://vercel.com) وسجّل بحساب GitHub.
2. **Add New… ← Project** ← اختر مستودع `jadeite-web` ← **Import**.
3. **لا تضغط Deploy بعد** — اذهب أولاً للخطوة ٣.

## الخطوة ٣ — أضف مفاتيح الاتصال (مهم)

في صفحة الاستيراد نفسها: **Environment Variables** ← أضف متغيرين:

| Name | Value |
|---|---|
| `SUPABASE_URL` | `https://ttpqksvtnhoulghgovob.supabase.co` |
| `SUPABASE_ANON_KEY` | `sb_publishable_ymRG7rKUf-704V3j1bNwgg_b1IvlMlX` |

> ⚠️ لا تضع `sb_secret_...` هنا إطلاقاً. المفتاح السري يتخطى كل الحمايات،
> ووضعه في تطبيق ويب يعني كشف بيانات كل عملائك لأي شخص يفتح الرابط.
> مفتاح `anon` آمن لأن سياسات RLS في Supabase هي التي تحمي البيانات فعلياً.

## الخطوة ٤ — Deploy

اضغط **Deploy** وانتظر ٥–١٠ دقائق (أول بناء يُنزّل Flutter، والمرات التالية أسرع).

ستحصل على رابط مثل:

```
https://jadeite-web.vercel.app
```

## الخطوة ٥ — افتحه من جوالك

1. افتح الرابط في Chrome على الجوال.
2. سجّل الدخول بحساب المدير.
3. من قائمة المتصفح: **إضافة إلى الشاشة الرئيسية** ← يصبح أيقونة مستقلة بلا شريط متصفح.

**أي تحديث لاحق:** `git push` فقط — Vercel يعيد البناء والنشر تلقائياً.

## ما تم ضبطه لواجهة الجوال

| العنصر | على الجوال |
|---|---|
| القائمة الجانبية | تتحوّل لقائمة هامبرغر ☰ تُفتح بالسحب أو بالضغط |
| الشريط العلوي | اسم المصنع والرصيد فوق بعض بدل صف واحد يفيض |
| الجداول | تمرير عرضي مع شريط تمرير مرئي — كل الأعمدة مقروءة بلا تكبير |
| بطاقات العملاء | الشارات تنزل لسطر جديد، والأزرار تحت البيانات بدل انضغاطها بجانبها |
| زر «دخول كالعميل» | ١٥٠×٤٦ بكسل — مساحة لمس مريحة لإصبع واحد |
| شريط انتحال الشخصية | ثابت أعلى الشاشة دائماً، يوضّح أي عميل معروض، وزر خروج بمساحة لمس كاملة |
| التكبير | ملغى الحاجة إليه (`viewport-fit=cover`) |

## حلول سريعة لمشاكل النشر

| المشكلة | الحل |
|---|---|
| البناء يفشل برسالة عن `SUPABASE_URL` | لم تُضف متغيرات البيئة — راجع الخطوة ٣ ثم **Redeploy** |
| صفحة بيضاء بعد النشر | افتح Console في المتصفح؛ غالباً المفتاح خاطئ أو ناقص |
| «Invalid API key» | نسخت المفتاح ناقصاً — أعد نسخه كاملاً من Supabase ← Settings ← API |
| التطبيق لا يُعرض عليه خيار التثبيت | لا بد أن يكون الرابط `https://` — روابط Vercel كذلك افتراضياً |
| بيانات قديمة بعد التحديث | اسحب الصفحة للأسفل لتحديثها؛ عامل الخدمة مضبوط على عدم التخزين |
